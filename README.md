Traffic Signs Identifier using CNN

A deep learning-based image classification system that identifies traffic signs from images using Convolutional Neural Networks (CNNs). The project leverages the German Traffic Sign Recognition Benchmark (GTSRB) dataset to train a model capable of accurately classifying various road signs, making it ideal for intelligent transportation systems and autonomous vehicle applications.

Features

Built with Python and TensorFlow/Keras.

Custom CNN architecture for high classification accuracy.

Includes preprocessing: resizing, normalization, and data augmentation.

Provides evaluation metrics: accuracy, confusion matrix, and classification report.

Test the model on custom traffic sign images.

Technologies

Python • TensorFlow / Keras • OpenCV • NumPy • Matplotlib • Scikit-learn

Applications

Driver assistance systems

Autonomous vehicles

Traffic sign recognition and analysis
