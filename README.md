Traffic Signs Identifier using CNN
This project is a deep learning-based image classification system designed to identify traffic signs from images using Convolutional Neural Networks (CNN). 
It leverages supervised learning techniques to classify images into various categories of road signs, making it suitable for intelligent transportation systems and autonomous vehicle applications.

Features:
Built using Python and TensorFlow/Keras.
Utilizes a custom-designed CNN architecture for high accuracy.
Trained on the German Traffic Sign Recognition Benchmark (GTSRB) dataset.
Includes preprocessing steps like resizing, normalization, and data augmentation.
Provides evaluation metrics such as accuracy, confusion matrix, and classification report.
Option to test model performance on custom traffic sign images.

Technologies Used:
Python
TensorFlow / Keras
OpenCV (for image handling and preprocessing)
NumPy, Matplotlib, Scikit-learn (for data analysis and visualization)

Applications:
Driver assistance systems
Autonomous vehicles
Traffic sign analysis and recognition systems
